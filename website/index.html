Welcome, geomodellers!

You’ve built a great 3D geological model. Now you want other people — colleagues, planners, students, or the public — to be able to explore it interactively online.

Geo3D Loader helps you do exactly that. It takes the surfaces from your modelling software and prepares them for the Geo3D Viewer, a free web-based platform developed by the Polish Geological Institute in collaboration with the British Geological Survey.

How it works in 4 steps

You don’t need to be a web developer. Just follow the path below.

1

Describe your geological units

Create a simple legend (names, colours, order) using the GVS tool. This tells the viewer what each layer represents.

2

Convert your surfaces

Run a small converter that turns your ASCII grids into optimised .g3d files and builds a basic project configuration.

3

Polish the presentation

Use the friendly Project Configurator to add a title, description, adjust colours, enable tools, and set the coordinate system.

4

Preview & Publish

Check how your model looks in the real viewer, then share it with the world.

Tip for newcomers: Start with the Getting Started guide. It walks you through the process with encouragement and clear next actions.

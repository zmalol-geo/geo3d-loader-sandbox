What you need before you start

You will need:

  • Your geological surfaces as ASCII grids (the common output from many 3D modelling packages).
  • A clear idea of the geological units (names, preferred colours, and stratigraphic order).
  • A Windows computer for the current converter tool (more platforms may come later).
  • About 30–60 minutes the first time you go through the process.
Good news: You do not need to write any code, set up a server, or understand JSON. The tools handle most of the technical work for you.

The big picture

The Geo3D Loader takes the surfaces from your modelling software and turns them into a format that the Geo3D Viewer can display in any modern web browser.

There are four main stages:

  1. Describe the geology – create a simple legend of your units.
  2. Convert the grids – turn ASCII files into optimised .g3d files.
  3. Configure the experience – add titles, colours, tools and settings.
  4. Preview and publish – check the result and share it.

You can move back and forth between stages. Nothing is final until you decide to publish.

Preparing your first model

Start small. Choose a model with a modest number of layers so you can learn the process without feeling overwhelmed. Once you have successfully published one model, the next ones become much easier.

1. Gather your ASCII grids

For each geological unit you normally need two grids (for example top + base, or top + thickness). Keep the naming consistent — the converter relies on it.

2. Create a simple legend

Use the GVS (Generalised Vertical Section) tool inside the Project Configurator. This is where you give each unit a name, a colour, and a place in the stratigraphic order.

3. Run the converter

The asc-to-g3d tool does the heavy lifting. It creates the .g3d files and a basic project configuration. You will find clear examples in the full workflow guide.

4. Improve the presentation

Open the generated project in the Project Configurator. Add a clear title and a short description so visitors understand what they are looking at. Adjust colours if needed and enable the tools you want people to use (cross-sections, virtual boreholes, etc.).

Current limitation: A proper in-workflow preview (seeing your model in the real Geo3D Viewer before final publishing) is still being developed. For now, careful checking of colours, order and settings in the Configurator is especially important.

Common feelings (and what helps)

  • “This feels technical.” → It is a bit technical the first time. Follow the steps one by one and you will get there.
  • “I’m not sure about the colours / order.” → You can always come back and change them later.
  • “I wish I could just see the model.” → You are not alone. A proper preview feature is high on the wishlist.
